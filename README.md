# موقع صيدلية الدكتور علي عباس

موقع عربي متجاوب لصيدلية الدكتور علي عباس في عين شمس الغربية، القاهرة. يتيح البحث في دليل للأدوية المتداولة في مصر، إضافة الأدوية إلى سلة محفوظة في المتصفح، ثم إرسال طلب السلة أو طلب دواء منفرد إلى الصيدلية **برسالة واتساب جاهزة**. يتضمن رابط الموقع والخريطة المضمّنة.

**العنوان:** ٩١ امتداد شارع المشروع، عين شمس الغربية، القاهرة. [افتح الموقع على خرائط جوجل](https://maps.app.goo.gl/Pmdh7Nh8gGHSpTdh9).

> **تنبيه:** بيانات الأدوية والأسعار من دليل خارجي، ولا تعكس مخزون الصيدلية الفعلي. الأسعار المعروضة استرشادية؛ السعر النهائي والتوفر ومتطلبات الروشتة يؤكدها الصيدلي. إرسال الرسالة هو طلب استفسار، وليس دفعًا إلكترونيًا أو تأكيدًا تلقائيًا للطلب.

## تشغيله على جهازك

المطلوب: Node.js الإصدار **20.19+** أو **22.12+**، وnpm، واتصال بالإنترنت لجلب دليل الأدوية الكامل.

1. فك ضغط ملف المشروع، وافتح الطرفية داخل مجلد `pharmacy-site` (المجلد الذي يحتوي `package.json`).
2. نفّذ:

   ```bash
   npm ci
   npm run dev
   ```

3. افتح الرابط الذي يظهر في الطرفية، وعادةً `http://localhost:5173/`.
4. للتأكد من نجاح البناء والاختبارات:

   ```bash
   npm test
   npm run build
   ```

> `node_modules` و`dist` غير موجودين داخل ملف ZIP عمدًا؛ `npm ci` يثبت الحزم تلقائيًا من `package-lock.json`.

## رفع المشروع إلى GitHub

أنشئ مستودعًا فارغًا على GitHub (من دون README مبدئي)، ثم نفّذ **داخل مجلد `pharmacy-site`**:

```bash
git init
git add .
git commit -m "Create Ali Abbas pharmacy website"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

استبدل `USERNAME` و`REPOSITORY` باسم حسابك ومستودعك. يمكنك أيضًا رفع الملفات عبر واجهة GitHub، لكن ارفع **محتويات مجلد `pharmacy-site`** إلى جذر المستودع، بحيث يظهر `package.json` في جذر المستودع.

## نشره على Vercel

1. ادخل إلى [vercel.com](https://vercel.com/) وسجّل دخولك بحساب GitHub.
2. اختر **Add New → Project** واستورد المستودع.
3. الإعدادات: **Framework Preset: Vite**، و**Build Command: `npm run build`**، و**Output Directory: `dist`** (ملف `vercel.json` يحددها بالفعل).
4. اترك **Root Directory** كما هو إذا كان `package.json` في جذر المستودع. إذا رفعت مجلد `pharmacy-site` نفسه داخل المستودع بدل محتوياته، اجعل Root Directory = `pharmacy-site`.
5. اضغط **Deploy**. لا تحتاج إلى مفاتيح API أو متغيرات بيئة.

## مصدر الأدوية وطريقة العمل

- المصدر العام المباشر: [Egyptian Drug Database — ملف JSON](https://raw.githubusercontent.com/karem505/egyptian-drug-database/main/data/egyptian-drugs.json). قاعدة البيانات [مفتوحة المصدر بترخيص CC0](https://github.com/karem505/egyptian-drug-database) وتضم نحو 25 ألف سجل بأسماء عربية/إنجليزية وأسعار بالجنيه. تُحمّل من الإنترنت في متصفح الزائر (مع رابط CDN احتياطي)، ثم يتم البحث والتصفية وترتيب النتائج محليًا، وعرض 12 منتجًا في كل دفعة.
- لا يُعرض الصنف الموسوم `(N/A)` في المصدر. تحميل القائمة الكاملة **لا يعني أن الأدوية متاحة في الصيدلية**؛ التأكيد يتم عبر واتساب.
- عند تعذر الاتصال يعرض الموقع نسخة محدودة من 45 دواء مع تنبيه ظاهر وزر «إعادة المحاولة»، بدلاً من شاشة خالية. هذه النسخة في `src/data/fallback-medicines.json`.
- السلة محفوظة محليًا في متصفح الزائر باستخدام `localStorage`. زر «شراء الآن» ينشئ رسالة للدواء وعبوته، وزر «اطلب من الصيدلية عبر واتساب» ينشئ رسالة بكل أدوية السلة وكمياتها. كلاهما موجّه إلى **01020345314**.
- الصورة الرئيسية داخل `public/images/` **صورة توضيحية مولّدة وليست صورة حقيقية للصيدلية**. استبدلها بصورة حقيقية إذا رغبت، مع إبقاء اسم الملف أو تعديل مساره في `src/App.tsx`.

## أماكن التعديل السريع

| ما تريد تغييره | الملف |
|---|---|
| رقم واتساب المعروض ورقم صيغة `wa.me` الدولية | `src/lib/order.ts` (`DISPLAY_PHONE` و`WHATSAPP_NUMBER`) |
| رابط خرائط جوجل وكود تضمين الخريطة | `src/config.ts` |
| نصوص الصيدلية والعنوان | `src/App.tsx` |
| مصدر بيانات الأدوية وبديل CDN | `src/lib/catalog.ts` |
| التصميم والألوان والتجاوب | `src/styles.css` |

**التقنيات:** React + TypeScript + Vite. الواجهة عربية RTL ومتجاوبة، ولا يتطلب النشر قاعدة بيانات أو خادمًا خاصًا.
